## Caveat, Contamination, and Leaderboard-Overfitting Sources

- LiveBench, for monthly fresh questions and contamination motivation: https://livebench.ai/
- LiveCodeBench, for continuously refreshed contest problems and post-release/live coding methodology: https://livecodebench.github.io/leaderboard.html
- Artificial Analysis LiveCodeBench, for independently reported contamination-free live benchmark framing: https://artificialanalysis.ai/evaluations/livecodebench
- BigCodeBench, for public benchmark contamination caveats and calibrated pass@1 framing: https://bigcode-bench.github.io/
- SWE-bench Verified, for scaffold, tool, and version comparability caveats: https://www.swebench.com/verified.html
- Aider Polyglot benchmark, for explicit pass-rate-1/pass-rate-2, edit format, cost, and command metadata showing scaffold sensitivity: https://aider.chat/docs/leaderboards/
- Arena coding leaderboard, for crowd-preference and public leaderboard incentives: https://arena.ai/leaderboard/text/coding
- SWE-rebench, for claims that static SWE agent benchmarks can become outdated and contaminated: https://arxiv.org/abs/2505.20411
- SWE-MERA, for dynamic benchmark design and reported contamination/test-adequacy concerns in existing SWE benchmarks: https://arxiv.org/abs/2507.11059
